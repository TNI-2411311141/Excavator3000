# Excavator3000 Weather Monitoring RC Car
Excavator3000 เป็นรถบังคับตรวจวัดสภาพแวดล้อมที่รวมระบบ IoT และปัญญาประดิษฐ์ ผู้ใช้สามารถบังคับรถไปยังจุดที่ต้องการเพื่อวัดอุณหภูมิและความชื้น ติดตามข้อมูลผ่านแดชบอร์ด และรับผลวิเคราะห์สภาพแวดล้อมจาก AI
## การทำงานของระบบ
ESP32 อ่านค่าอุณหภูมิและความชื้นจากเซนเซอร์ DHT11 แสดงข้อมูลบนจอ OLED และส่งข้อมูลผ่าน Wi-Fi ด้วยโปรโตคอล MQTT ไปยัง Node-RED เพื่อแสดงค่าที่ตรวจวัดและสถานะรถแบบเรียลไทม์ จากนั้น Node-RED ส่งข้อมูลไปยัง Forge AI Harness ซึ่งใช้โมเดล Qwen3.5 27B ผ่าน Ollama เพื่อวิเคราะห์และส่งผลกลับมาแสดงบนแดชบอร์ด
## ความสามารถหลัก
- ตรวจวัดและแสดงอุณหภูมิและความชื้น
- แสดงข้อมูลและสถานะการเชื่อมต่อบนจอ OLED
- แสดงค่าที่ตรวจวัดและสถานะรถผ่านแดชบอร์ด Node-RED
- หยุดการทำงานเมื่อเกิดการชน พร้อมไฟ LED แสดงสถานะ
- ควบคุมการข้ามระบบป้องกันการชน (Safety Bypass) ผ่านปุ่มบนรถและแดชบอร์ด
- วิเคราะห์ข้อมูลสภาพแวดล้อมด้วย AI
## อุปกรณ์และซอฟต์แวร์หลัก
ESP32, DHT11, เซนเซอร์ตรวจจับการชน, จอ OLED, ไฟ LED, ปุ่ม Bypass และชุดรถบังคับพร้อมบอร์ดรับสัญญาณ RF โดยใช้ PlatformIO สำหรับพัฒนาโปรแกรม และใช้ MQTT Broker, Node-RED, Forge AI Harness และ Ollama เป็นส่วนประกอบของระบบซอฟต์แวร์
## การเชื่อมต่อ
รถเชื่อมต่อผ่าน Wi-Fi ย่าน 2.4 GHz เช่น ฮอตสปอตจากโทรศัพท์ โดย ESP32 และเครื่องที่ให้บริการ MQTT/Node-RED ต้องสามารถติดต่อกันผ่านเครือข่ายได้ ส่วนการวิเคราะห์ผ่าน Forge AI Harness ต้องมีการเชื่อมต่ออินเทอร์เน็ต
